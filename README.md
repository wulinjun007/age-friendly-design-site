# 适老化设计手册(Age-Friendly Design Handbook)

一个关于**适老化设计**的静态知识库网站:讲清知识点的来源、背后的设计思路与落地参数,覆盖数字产品与空间环境两大场景。**本站自身即适老化示范**。

## 打开方式

无需构建、无外部依赖、可离线使用,直接双击 `index.html` 即可;或起本地服务:

```bash
cd age-friendly-design-site
python3 -m http.server 8747
# 浏览器打开 http://localhost:8747
```

## 页面结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 总览:定义、人口与政策背景、四大设计思路(放大/减法/兜底/尊重) |
| `aging.html` | ① 认识用户:视觉/听觉/运动/认知变化 → 设计含义,附**视觉模拟器** |
| `principles.html` | ② 设计原则:通用设计七原则、适老五原则、核心量化指标速查表 |
| `digital.html` | ③ 数字产品:排版/色彩/触控/导航/表单/反馈/语音,附**对比度演示器**与**热区演示** |
| `space.html` | ④ 空间环境:通行、卫生间、起夜动线、照明、智能家居、尺寸速查表 |
| `standards.html` | ⑤ 标准规范:WCAG、GB 55019、JGJ 450、工信部 App 适老规范要点、验收方法 |
| `cases.html` | ⑥ 案例拆解:验证码/诱导弹窗/图标导航/日期选择好坏对比 + 真实产品分析 |
| `process.html` | ⑦ 流程自查:用户研究方法、可用性测试指标、**20 条可打印走查清单** |

## 知识点组织方式

每条知识点按四段展开:**知识点 → 背后的道理 → 落地细节 → 常见误区**。

## 站点自身的适老化特性(示范点)

- 正文 18px 起步,右上角三档字号切换(标准/大/特大),localStorage 记忆
- 高对比模式(纯黑白 + 强描边)
- 可点目标 ≥ 44×44px、无汉堡菜单、无悬停依赖、无时间限制
- 键盘完整可用:跳转链接、可见焦点、aria-current 导航、aria-live 播报
- 动效遵循 `prefers-reduced-motion`;语义化标签兼容读屏
- 所有演示控件均为原生表单元素 + 大号尺寸

## 技术说明

纯 HTML + CSS + 原生 JS,零依赖,零构建。样式 `assets/css/style.css`(全部尺寸用 rem,字号切换即根字号缩放),脚本 `assets/js/main.js`(显示偏好 + WCAG 对比度计算演示)。

> 站内参数(对比度、触控尺寸、建筑尺寸等)为 WCAG / 国家规范与主流实践的常用参考值,工程落地请以现行规范原文与实测为准。
